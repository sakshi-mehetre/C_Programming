# Assignment 23 – String Operations in C

## Description
This assignment contains C programs based on string manipulation and character operations using pointers, loops, conditional statements, and ASCII values.

## Programs Included

| No. | Program Name | Description |
|---|---|---|
| 1 | strlwrx | Accepts a string and converts all uppercase characters into lowercase. |
| 2 | struprx | Accepts a string and converts all lowercase characters into uppercase. |
| 3 | strtoggle | Accepts a string and converts uppercase characters into lowercase and lowercase characters into uppercase. |
| 4 | DisplayDigit | Accepts a string and displays only the digits present in it. |
| 5 | CountWhite | Accepts a string and counts the number of white spaces in it. |

## Concepts Used
- Strings in C
- Character Pointers
- Pointer Arithmetic
- String Traversal
- ASCII Values
- While Loop
- If-Else Statements
- Character Manipulation
- Uppercase and Lowercase Conversion
- Digit Extraction
- Counting White Spaces
