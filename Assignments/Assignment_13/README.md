# Assignment 13 – Number Digit Operations in C

## Description
This assignment contains C programs based on digit operations using user-defined functions, loops, conditional statements, and arithmetic operators.

## Programs Included

| No. | Program Name | Description |
|---|---|---|
| 1 | CountEven | Counts the number of even digits in the given number. |
| 2 | CountOdd | Counts the number of odd digits in the given number. |
| 3 | CountRange | Counts the digits between 3 and 7 (inclusive). |
| 4 | MultDigits | Returns the multiplication of all non-zero digits in the given number. |
| 5 | CountDiff | Returns the difference between the sum of even digits and the sum of odd digits. |

## Concepts Used
- User-Defined Functions
- While Loop
- If-Else Statements
- Logical AND Operator (`&&`)
- Modulus Operator (`%`)
- Division Operator (`/`)
- Digit Extraction
- Counter Variables
- Arithmetic Operations
