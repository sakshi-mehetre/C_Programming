# Assignment 22 – C Programming

## Description

This assignment contains C programs based on character, number, and special symbol patterns using loops. The programs accept a number from the user and display different sequences using characters, numbers, and special symbols.

## Programs List

| Sr. No. | Program Name | Description |
| ------- | ------------ | ----------- |
| 1 | Pattern | Displays uppercase alphabets starting from `A`. |
| 2 | Pattern | Displays descending numbers with alternate `#` symbols. |
| 3 | Pattern | Displays ascending numbers with alternate `*` symbols. |
| 4 | Pattern | Displays numbers between `#` and `*` symbols. |
| 5 | Pattern | Displays even numbers up to twice the given input. |

## Program Details

### 1. Pattern – Uppercase Alphabet Sequence

- Accepts a number from the user.
- Displays uppercase alphabets starting from `A`.
- Prints the specified number of consecutive alphabets.
- Uses a character variable and a `for` loop.

### 2. Pattern – Descending Number with Hash Symbols

- Accepts a number from the user.
- Displays numbers in descending order, starting from the given number and ending at `1`.
- Prints a `#` symbol after every number.
- Uses a decrementing `for` loop.

### 3. Pattern – Ascending Number with Star Symbols

- Accepts a number from the user.
- Displays numbers in ascending order, starting from `1`.
- Prints a `*` symbol after every number.
- Uses an incrementing `for` loop.

### 4. Pattern – Number with Hash and Star Symbols

- Accepts a number from the user.
- Displays a `#` symbol before every number.
- Displays a `*` symbol after every number.
- Prints numbers in ascending order from `1` to the given number.

### 5. Pattern – Even Number Sequence

- Accepts a number from the user.
- Displays even numbers from `2` up to twice the given input.
- Uses a `for` loop and modulus operator (`%`) to identify even numbers.
