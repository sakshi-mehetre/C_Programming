# Assignment 12 – Number Digit Operations in C

## Description
This assignment contains C programs based on number digit operations using functions, loops, conditional statements, and arithmetic operators.

## Programs Included

| No. | Program Name | Description |
|---|---|---|
| 1 | DisplayDigit | Accepts a number and displays its digits in reverse order. |
| 2 | ChkZero | Checks whether the given number contains zero or not. |
| 3 | CountTwo | Counts the frequency of digit 2 in the given number. |
| 4 | CountFour | Counts the frequency of digit 4 in the given number. |
| 5 | Count | Counts the digits that are less than 6 in the given number. |

## Concepts Used
- User-defined Functions
- While Loop
- If-Else Statements
- Modulus Operator (`%`)
- Division Operator (`/`)
- Digit Extraction
- Counter Variables
- Boolean Data Type
