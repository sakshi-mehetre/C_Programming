# Assignment 15 – Basic Operations and User-Defined Functions in C

## Description
This assignment contains C programs based on string input, comparison of numbers, multiplication, and percentage calculation using user-defined functions, conditional statements, and basic C programming concepts.

## Programs Included

| No. | Program Name | Description |
|---|---|---|
| 1 | Display Name | Accepts the full name from the user and displays it. |
| 2 | ChkGreater | Checks whether the given number is greater than 100 or not. |
| 3 | ChkEqual | Checks whether two given numbers are equal or not. |
| 4 | Multiply | Accepts three numbers and returns their multiplication, ignoring zero values. |
| 5 | Percentage | Calculates the percentage using total marks and obtained marks. |

## Concepts Used
- User-Defined Functions
- Character Arrays
- String Input and Output
- Conditional Statements (If-Else)
- Boolean Data Type
- Relational Operators
- Arithmetic Operators
- Type Casting
- Percentage Calculation
