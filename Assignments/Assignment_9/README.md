# Assignment 9 – Patterns, Currency Conversion, and Factorials

## Description
This assignment contains C programs based on pattern printing, currency conversion, even factorial, odd factorial, and factorial difference. These programs demonstrate the use of user-defined functions, loops, conditional statements, and arithmetic operations.

## Programs

### 1. Pattern Display (`program9_1.c`)
Accepts a number from the user and displays a pattern of `*` and `#` symbols. It prints the first half using `*` and the second half using `#`.

**Example:**
```text
Enter number : 5
*       *       *       *       *       #       #       #       #       #
```

### 2. Dollar to Indian Rupees Conversion (`program9_2.c`)
Accepts an amount in US dollars and converts it into Indian rupees using a conversion rate of ₹70 per USD.

**Example:**
```text
Enter number of USD : 10
Indian Currency is: 700
```

### 3. Even Factorial (`program9_3.c`)
Accepts a number from the user and calculates the product of all even numbers from 1 up to the given number.

**Example:**
```text
Enter number : 6
Even Factorial of number is 48
```

### 4. Odd Factorial (`program9_4.c`)
Accepts a number from the user and calculates the product of all odd numbers from 1 up to the given number.

**Example:**
```text
Enter number : 5
Even Factorial of number is 15
```

### 5. Factorial Difference (`program9_5.c`)
Accepts a number from the user and calculates the difference between the even factorial and odd factorial.

**Example:**
```text
Enter number : 5
Factorial difference is -9
```

## Concepts Covered
- User-defined functions
- `for` loops
- Conditional statements
- Pattern printing
- Currency conversion
- Even and odd number checking
- Factorial calculation
- Arithmetic operations

## How to Compile and Run

Compile a program using GCC:

```bash
gcc program9_1.c -o myexe
```

Run the executable:

```bash
./myexe
```

On Windows Command Prompt:

```bash
myexe.exe
```

Replace `program9_1.c` with the required program filename.
