# Assignment 25 – Character Operations in C

## Description
This assignment contains C programs based on character checking and classification, such as alphabet checking, uppercase and lowercase identification, digit checking, and displaying examination schedules based on student division.

## Programs Included

| No. | Program Name | Description |
|---|---|---|
| 1 | CharAlpha | Checks whether the given character is an alphabet or not. |
| 2 | ChkCapital | Checks whether the given character is an uppercase alphabet or not. |
| 3 | ChkDigit | Checks whether the given character is a digit or not. |
| 4 | ChkSmall | Checks whether the given character is a lowercase alphabet or not. |
| 5 | DisplaySchedule | Accepts the student's division and displays the corresponding examination timing. |

## Concepts Used
- Character Data Type
- User-Defined Functions
- Boolean Data Type
- If-Else Statements
- ASCII Values
- Character Comparison
- Relational Operators
- Logical Operators
- Conditional Statements
