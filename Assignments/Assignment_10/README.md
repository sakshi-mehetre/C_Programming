# Assignment 10 – Area and Unit Conversion

## Description
This assignment contains C programs based on calculating the area of geometric shapes and converting measurement units. These programs demonstrate the use of user-defined functions, floating-point values, and arithmetic operations.

## Programs

### 1. Area of Circle (`program10_1.c`)
Accepts the radius of a circle from the user and calculates its area using the formula:

**Area = π × radius × radius**

The value of π used in the program is 3.14.

**Example:**
```text
Enter number : 5
Area of circle is 78.500000
```

### 2. Area of Rectangle (`program10_2.c`)
Accepts the width and height of a rectangle and calculates its area using the formula:

**Area = Width × Height**

**Example:**
```text
Enter width: 5
Enter height: 4
Area of rectangle is 20.000000
```

### 3. Kilometer to Meter Conversion (`program10_3.c`)
Accepts a distance in kilometers and converts it into meters.

**Formula:**

1 Kilometer = 1000 Meters

```text
Enter Distance: 5
covert to meter is 5000
```

### 4. Fahrenheit to Celsius Conversion (`program10_4.c`)
Accepts the temperature in Fahrenheit and converts it into Celsius using the formula:

**Celsius = (Fahrenheit − 32) × 5 / 9**

**Example:**
```text
Enter Temperaturn in Fahrenheit 98.6
Temperature in Celsius 37.000000
```

### 5. Square Feet to Square Meter Conversion (`program10_5.c`)
Accepts an area in square feet and converts it into square meters.

**Conversion factor:**

1 Square Foot = 0.0929 Square Meter

**Example:**
```text
Enter area in square feet : 100
Area in square meter 9.290000
```
