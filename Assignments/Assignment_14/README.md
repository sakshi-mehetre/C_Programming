# Assignment 14 – Factors Operations in C

## Description
This assignment contains C programs based on factors and non-factors of a given number using user-defined functions, for loops, conditional statements, and arithmetic operators.

## Programs Included

| No. | Program Name | Description |
|---|---|---|
| 1 | MultFact | Calculates and returns the multiplication of all factors of the given number (excluding the number itself). |
| 2 | FactRev | Displays all factors of the given number in decreasing order. |
| 3 | NonFact | Displays all non-factors of the given number. |
| 4 | SumNonFact | Calculates and returns the sum of all non-factors of the given number. |
| 5 | FactDiff | Returns the difference between the sum of factors and the sum of non-factors of the given number (excluding the number itself). |

## Concepts Used
- User-Defined Functions
- For Loop
- If-Else Statements
- Modulus Operator (`%`)
- Division Operator (`/`)
- Factor Calculation
- Multiplication of Factors
- Summation
- Difference Calculation
